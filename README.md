# Калькулятор

Простой калькулятор с веб-интерфейсом и отдельной реализацией на Python.

## ▶ Запустить калькулятор

**[Открыть веб-версию](./)**

Веб-версия работает прямо в браузере и не требует установки дополнительных программ.

## Python

В проекте также есть отдельная простая реализация калькулятора на Python.

Она использует базовые конструкции языка: переменные, ввод данных и условные операторы.

Файл:

`python/calculator.py`

## О проекте

Проект создан как небольшой пример работы с HTML, CSS, JavaScript и Python.

Веб-версия показывает готовый пользовательский интерфейс, а Python-версия демонстрирует ту же основную задачу с использованием базовых конструкций Python.
